# 歴史ならべ

日本の歴史のできごとの札を、古い順に押して年表にする1日5問のゲーム。並べると、年と一言の説明が出ます。時間制限なし、押すだけ。

- 遊ぶ: https://satou-aaaaa.github.io/rekishi-narabe/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（5枚ならべ×3問・ヒントなし）、練習（難しさか時代を選んで何度でも）、とことん（何問続けて並べられるか）、並べたできごとが年といっしょに集まる「年表帳」があります。
- 知らなくても遊べます。ヒントは「札に時代を出す」→「次の1枚を置く」の2段。画面の下に、時代の順のものさしがあります。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、文字の大きさ3段があります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 年の出どころ

- 年は、学校の日本史で広く使われている年（西暦）です。旧暦の年を西暦に合わせて書いています。
- 年がはっきりしないできごと・説が分かれるできごと（仏教が伝わった年、鎌倉幕府ができた年など）は入れていません。
- 例：伊能忠敬の日本地図（大日本沿海輿地全図）の完成は1821年（[国土地理院](https://www.gsi.go.jp/MUSEUM/SOUGO/kohokocho20211019_00001.html)）。
- 自分で思い出して答えると覚えやすく（[Adesope ほか 2017](https://journals.sagepub.com/doi/10.3102/0034654316689306)）、間をあけてくり返すと長く覚えていられます（[Cepeda ほか 2006](https://pubmed.ncbi.nlm.nih.gov/16719566/)）。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（できごとと年は入りません）。
